Bundled CLI sample

Try local S3 with sample files.

Run one command to start a temporary server with an assets bucket and local-stack fixture.

recorded terminal
$ s3dir demo --port 9000

demo files   /tmp/s3dir-demo-2ef5
s3dir ready  http://127.0.0.1:9000
console      http://127.0.0.1:9000/ui
directory    /tmp/s3dir-demo-2ef5
seeded       3 files

$ curl http://127.0.0.1:9000/assets/welcome.txt
Welcome to the s3dir sample bucket.

Sample files

Open these files in the local console.

  • assets/welcome.txtText object for a first GET.
  • assets/receipts/may-2026.txtNested object for a key path.
  • fixtures/local-stack.jsonFixture for an application endpoint.

The temporary directory is separate from your project.
