How it maps

Map one directory to local S3.

Buckets are folders. Keys are paths. Metadata and tags use hidden sidecar files.

./data/assets/avatars/ada.webp→s3://assets/avatars/ada.webp

Browser console

Inspect local uploads in your browser.

Use the local /ui console to browse buckets, edit text, upload files, and remove test data.

The public site is a recorded sample. Your local server provides the working console.

Use the operations your application needs.

    Create buckets, store objects, list keys, and read byte ranges.

  • 03Local testing

Development use only. It does not provide IAM, versioning, replication, or durability guarantees.

Installation

Start one binary against one directory.

Build from source, then open the printed local console URL.

The server allows 300 requests per client every 60 seconds. Extra requests receive 429 and Retry-After.

terminal
$ cargo install --path .
$ s3dir serve ./data --port 9000

s3dir ready  http://127.0.0.1:9000
console      http://127.0.0.1:9000/ui
directory    ./data
