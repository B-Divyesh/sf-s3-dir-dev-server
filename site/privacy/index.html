Privacy

s3dir is local-first software. The CLI does not include analytics, telemetry, accounts, or remote storage.

Data processed by the CLI

Object bytes, metadata, and tags are written only to the directory you choose. The browser console communicates directly with your local s3dir process. Nothing is sent to Sociobot.

Optional webhooks

If you pass --events, object event details are sent to the URL you explicitly provide. You control that recipient and its privacy practices.

This website

The documentation site uses no analytics, cookies, third-party fonts, or third-party scripts. Its service worker caches public page assets on your device for offline use.
